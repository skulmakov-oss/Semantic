# Wordmark provenance

Lowercase `semantic` is outlined from Open Sans ExtraBold, version 1.10.
This is an open-source substitute for the specified heavy grotesk character;
it introduces no runtime font dependency. The paths, rather than a font file,
are the canonical reproduction assets. No font files are committed.

Font SHA-256: `0fcbdb5cbeea00ae532352c7c94a7d288ebc911ba85f4d595012032dcab64ba8`.
Upstream project: https://github.com/googlefonts/opensans.
The source font was already installed locally; no font was downloaded.

Modification: only the glyph outlines for `semantic` are extracted, positioned,
and filled near-black or white. The typeface is not attributed to Paul Rand.
For the same hash of the licensed source font and fontTools 4.57.0, use
`python scripts/brand/export_assets.py --wordmark-font PATH` to regenerate.
Ordinary PNG exports do not require this font or fontTools.
