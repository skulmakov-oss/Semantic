# Verifier As Semantic Exoskeleton

Status: language-experience design note

## Purpose

This document records the verifier-first framing as an exoskeleton for
Semantic.

## Meaning

The verifier is the structural support that keeps Semantic honest.

It is not the core meaning itself, but it surrounds the meaning and preserves
the admission boundary.

Recommended framing:

- canonical lowering stays visible;
- verifier admission stays explicit;
- runtime execution happens only after admission;
- the user experience should feel protected, not silently rewritten.

## Non-Goals

This document does not change verifier policy or widen admission.
