# Semantic Language Non-Goals

Status: language-experience design note

## Purpose

This document records what the language-experience track does not promise.

## Non-Goals

- no new syntax is implemented just because it is documented;
- no verifier widening;
- no VM widening;
- no SemCode widening;
- no hidden truthiness model;
- no implicit `quad -> bool`;
- no release-status widening;
- no UI authority.

## Use

Keep these non-goals visible whenever language experience docs describe a new
surface form or a new framing pattern.
