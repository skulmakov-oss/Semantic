# Post-UI / UI-DNA Roadmap Records (Retired)

Status: retired contour — historical record

This directory holds the design, audit, and ledger records of the former
post-UI / UI-DNA native UI track (projection, renderer, layout, native backend,
Shell Player, calculator and Workbench-adjacent work).

That track is **retired** together with native Semantic UI, Workbench, and
Semantic Studio (#1968 and #1862 closed as not planned). See
[UI, Workbench, and Studio retirement](../ui_workbench_studio_retirement.md).

How to read these files:

- they are preserved as written for their era and are not rewritten;
- statuses such as "frozen", "landed", "closed", or "next" inside them describe
  the track at the time, not a current roadmap commitment;
- no file here is a qualification gate, release claim, or Stable Foundation
  input;
- open items and known defects recorded here are not being remediated;
- some older files quote machine-local working directories as historical
  command evidence; they are not repository paths.

The active strategic direction is Semantic self-hosting
([#1910](https://github.com/skulmakov-oss/Semantic/issues/1910)).
