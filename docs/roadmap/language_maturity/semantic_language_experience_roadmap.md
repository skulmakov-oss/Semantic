## Purpose

This roadmap records the user-facing experience track for Semantic as a
language.

It is a documentation roadmap, not an implementation promise.

## Sequence

1. emotional contract
2. onboarding narrative
3. action vocabulary
4. code style principles
5. freedom with a spine
6. visible conflict handling
7. visible uncertainty handling
8. positive quad handling pattern
9. conflict quarantine UX pattern
10. non-goals
11. examples and cross-links
12. closeout record

## Guardrails

- do not claim grammar or runtime changes from the roadmap alone;
- keep `bool` / `quad` separation explicit;
- keep canonical lowering visible;
- keep verifier-first admission visible;
- keep examples clearly labeled as proposed when they are not yet implemented.
